# T2. 제품 재기획 (v0.2)

## 1. 한 줄 정의
**"저장만 해 두면, 그날의 컨셉에 맞는 하루 데이트 코스를 짜 주는 앱"**
— 20대 커플이 인스타·네이버에서 모아 둔 장소를, 영업시간·이동시간·예산까지 맞춰 바로 갈 수 있는 순서로 만들어 준다.

## 2. 사용자 흐름
```
① 저장        링크 붙여넣기 / 캡쳐 올리기(여러 장 가능: 홈·메뉴·정보 탭)
② 정리(자동)   장소 카드 생성 → 부족한 정보는 "정보 탭 캡쳐를 더 올려 주세요" 안내
③ 코스 요청    날짜·시작/끝 시간·출발지·이동 수단·컨셉·예산 선택
④ 추천        코스 3개(시간표 + 구간 이동시간 + 예상 비용 + 추천 이유 + 주의사항)
⑤ 확정·기록    다녀온 곳 표시 → 다음 추천에서 "새로운 곳" 가중치
```

## 3. MVP 범위
| 포함 (v0.2) | 제외 (다음 단계) |
|---|---|
| 하루 코스(2~5곳, 한 지역) | 1박 이상 여행 일정 |
| 컨셉 9종 + 이동 수단 4종(사용자 선택) | 실시간 길찾기·대중교통 경로 |
| 저장한 장소 안에서만 추천 | 저장 안 한 장소 탐색·광고 |
| 무료 데이터: 크롤링(robots.txt 준수) + OCR | 유료 지도·장소 API |
| 영업시간·예산·체류시간 제약 | 날씨 API 연동 (대신 "실내 위주" 토글) |

## 4. 장소 정보 항목과 우선순위
P0 = 코스 추천에 꼭 필요 · P1 = 추천 품질 향상 · P2 = 표시용

| 항목 | 우선순위 | 주 출처 | 없으면 |
|---|---|---|---|
| 이름·카테고리·좌표 | P0 | 링크/OCR + 주소 | 코스 후보에서 제외 (좌표 없으면 동선 계산 불가) |
| 요일별 영업시간·휴무·브레이크·라스트오더 | P0 | 정보 탭 캡쳐 OCR | "영업시간 미확인" 경고 + 감점 |
| 체류시간 | P0 | 카테고리 기본값 | 기본값 사용 |
| 1인 예상 비용 | P0 | 메뉴 가격 → 추정 | 가격대(1~4)로 대체, 없으면 예산 계산 제외 |
| 데이트 태그(분위기·상황) | P1 | 캡션·블로그·LLM | 컨셉 점수 낮음 |
| 예약 방식·필수 여부 | P1 | 플레이스 화면(캐치테이블·N예약) | "예약 여부 미확인" |
| 실내/실외 | P1 | 카테고리·태그 | 카테고리로 추정 |
| 평점·리뷰 수 | P1 | 플레이스 화면 OCR | 점수에서 제외 |
| 가까운 역·출구·거리 | P2 | 플레이스 화면 OCR | 표시 안 함 |
| 주차·편의 | P2 | 플레이스 화면 OCR | 표시 안 함 |
| 필드별 출처·수집일 | 시스템 | 자동 | — |

## 5. 컨셉별 코스 규칙
각 컨셉은 **순서 있는 슬롯**(허용 카테고리) + **선호 태그** + **식사 시간대 보너스**로 정의합니다. 슬롯에 맞는 저장 장소가 없으면 그 슬롯은 건너뜁니다(최소 2곳).

| 컨셉 | 슬롯 순서 | 선호 태그 |
|---|---|---|
| 맛집투어 | 맛집 → 디저트 카페 → 맛집/술집 → 카페 | 웨이팅있음(인기), 힙한 |
| 액티비티 | 체험 → 맛집 → 체험/전시 → 카페/술집 | 이색적인 |
| 기념일 | 전시/체험(사진·공방) → 맛집 → 바 | 기념일, 고급스러운, 뷰맛집, 야경, 프로포즈 |
| 카페투어 | 카페 → 전시/쇼핑 → 카페 → 카페 | 감성, 뷰맛집, 조용한 |
| 전시·문화 | 전시 → 카페 → 전시/쇼핑 → 맛집 | 이색적인, 감성 |
| 실내(비 오는 날) | 전시/체험 → 맛집 → 카페 → 술집 | 실내 |
| 산책·자연 | 자연 → 카페 → 자연/쇼핑 → 맛집 | 실외, 뷰맛집 |
| 술 한잔 | 맛집 → 술집 → 술집 | 늦게까지영업, 야경 |
| 첫데이트 | 카페 → 전시/체험 → 맛집 | 첫데이트, 조용한 |

## 6. 코스 점수 (요약)
`점수 = 컨셉 적합(카테고리·태그) + 식사시간 보너스 + 평점 + 정보 신뢰도 − 이동시간 − 대기시간 − 예산 초과 − 영업시간 미확인`
하드 제약: **영업시간 밖 방문 금지, 끝 시간 초과 금지, 같은 장소 중복 금지.**

## 7. 성공 기준 (v0.2)
- 가상 시나리오에서 영업시간·끝 시간 위반 0건
- 코스 1개 계산 0.5초 이내(저장 장소 50곳 기준)
- 플레이스 캡쳐 1장에서 이름·카테고리·주소·전화·평점·역·편의 추출
